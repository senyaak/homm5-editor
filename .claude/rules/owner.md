# Talking with the owner

- Repo files, commits, issues and PRs are English; the chat is in the owner's language.
- A term or abbreviation is spelled out and explained in one plain sentence the first time it comes up.
- Every list item has a marker the owner can cite (`1.`, `а)`), one list per message; several topics → letters outside, numbers inside.
- A report says what changed in plain words first, the terms in brackets after.
- No time estimates: size is said as what it contains (files, a migration).
- A question, an idea or a design talk is answered, not acted on: files change when the owner says so.
