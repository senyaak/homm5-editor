# Factions 3 — the test in the game

**What.** Prepare the install (a live run of the whole suite, the QoL settings
noted for the owner to reapply) and a probe map, and write the owner a
checklist of what to see, one line each: start a game as the race, the town
screen and its buildings, building every level, hiring every tier, the hero
and his class/racial, the siege, the guild, the random map with the race, an
AI player of the race for a few weeks.

**Source.** [factions-1-audit-race-readers.md](factions-1-audit-race-readers.md)
and [factions-2-e2e-gaps.md](factions-2-e2e-gaps.md) closed first.

**Acceptance.** The owner's answers are recorded; each problem found becomes a
bug item.

**Depends on.** factions-1-audit-race-readers, factions-2-e2e-gaps.

**Needs.** The owner plays the checklist.
