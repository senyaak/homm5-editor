# The random map generator, as the executable lays it out

Generated by `node tools/reverse/rmg-map.ts` — do not edit by hand.
`npm run test-rmg-map` fails when the executable no longer says this.

Addresses are from the unwrapped `bin/H5_Game_H5E.exe` and are landmarks,
not constants: another build is another compilation. What survives a build
is the *shape* — the phases, their order, and what each one reports.

## GenerateMap (0xeab460 .. 0xeac3dc)

The whole run, in the order the code is written. `Rnd Counter(x)` reads the
draw count so far; `at %g …` reports a step that just finished with the
seconds it took. Two different things worth two different columns: the
counter is the lockstep check a port is measured against, the step names
are the module list.

one function often carries several, which is how the order *within* a zone
is known. The "cannot place" lines are the constraints — each one is a rule
the port has to reproduce, stated by the code that gives up on it.
